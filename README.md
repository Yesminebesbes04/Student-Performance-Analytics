# Student Performance Analytics

## Overview

A data analytics project developed using Python and Pandas to clean, transform, and analyze student performance data.

## Dataset

The dataset contains information about:

- Student IDs
- Study hours
- Attendance rate
- Previous grades
- Exam scores

## Tools

- Python
- Pandas
- Google Colab

## Data Pipeline

### Data Cleaning

- Removed duplicates
- Converted text values to numeric formats
- Filtered invalid records

### Data Transformation

- Created grade categories
- Grouped attendance levels

### Data Analysis

- Calculated average scores
- Student grouping analysis
- Correlation analysis

## Key Findings

- Higher study hours tend to be associated with better exam scores.
- Students with high attendance generally achieve better results.
